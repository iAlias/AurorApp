# AurorApp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Costruire AurorApp — PWA offline che genera piani giornalieri di attività per una bimba di 3 anni (92 giorni estivi, mai ripetizioni entro 14 giorni) con timer pasti arcobaleno a prova di bimba.

**Architecture:** React SPA con logica pura isolata in `src/core/*` (zero React, 100% testata, deterministica), schermate in `src/features/*`, design system in `src/ui/*`, stato Zustand persistito in localStorage con envelope versionata. Spec normativa: `docs/superpowers/specs/2026-07-04-aurorapp-design.md` (+ catalogo attività collegato).

**Tech Stack:** React 18 + TypeScript strict + Vite 5 · Tailwind CSS 3 · Framer Motion 11 · Zustand 4 · zod 3 · date-fns 3 · canvas-confetti · Vitest + Testing Library · Playwright · vite-plugin-pwa.

## Global Constraints

- TypeScript `strict: true`; zero `any` non giustificati (NFR-7).
- `src/core/**` non importa MAI da `features/`, `ui/`, `app/`, react o dom; tempo e random sempre parametri (§6.1).
- Animazioni: solo `transform` e `opacity`; `prefers-reduced-motion` ⇒ fade 150 ms (NFR-3, §9.3).
- Lingua UI: solo it-IT; date con `date-fns` locale `it`; settimana da lunedì (NFR-6).
- Zero richieste di rete a runtime; font self-hosted via @fontsource; niente analytics (NFR-4).
- Chiave storage `aurorapp.state.v1`, `schemaVersion: 1` (§6.3).
- ID attività del catalogo stabili, formato `MOT-01`…`CAL-15`, 150 totali (catalogo v1.0).
- Ogni task si chiude SOLO con `npm run check` verde (typecheck+lint+unit+build) + commit.
- Colori arcobaleno (esterno→interno): `#FF5D5D #FF9A3D #FFD166 #7BC950 #4CC9F0 #5E7CE2 #9B5DE5`; spento `#E8E4DA` op. 0.6 (§8.2).
- Palette: sun `#FFD166` coral `#EF476F` aqua `#06D6A0` sky `#4CC9F0` deep `#073B4C` cream `#FFF8E7` card `#FFFFFF` stone `#8A857B` (§9.1).
- Timer: progresso SEMPRE derivato da timestamp (`startedAt`, `pausedTotalMs`), mai contatori (§8.1).
- Deviazioni approvate rispetto alla spec (documentate qui, decise per robustezza/zero-asset a runtime): suoni sintetizzati con WebAudio invece di file mp3 (stessa palette sonora §9.4); avatar = 8 emoji in cerchi colorati (ids invariati step 2 wizard); fallback Wake Lock = hint testuale (niente video 1×1); icone PWA generate a build-time con `sharp` (devDependency, mai nel bundle runtime) invece di un encoder PNG scritto a mano.

```ts
export function hashSeed(s: string): number {
  let h = 0x811c9dc5;
  for (let i = 0; i < s.length; i++) {
    h ^= s.charCodeAt(i);
    h = Math.imul(h, 0x01000193);
  }
  return h >>> 0;
}
export function mulberry32(seed: number): () => number {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```

```ts
      a.id !== excludeId &&
      (slot.onlyCategory ? a.category === slot.onlyCategory : true) &&
      !recent.has(a.id) &&
      (allowRepeatCategory || slot.onlyCategory || !dayState.usedCategories.has(a.category)) &&

      placeOk(a, ctx.profile.spaces) &&
```
